# ZStack-UI-Utils

Common Utils For ZStack UI

## Install

```sh
pnpm add @zstack/zsphere-utils
```

## Usage

```javascript
import { getGQL } from "@zstack/zsphere-utils";
```

## Test

```sh
pnpm test
```

## build

```sh
pnpm build
```
